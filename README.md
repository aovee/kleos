# Kleos

Kleos is a fan-made idle game inspired by the Greek mythos. You battle through Mount Olympus or the Underworld, unlocking new gods and abilities along the way. The game is designed to be a single-player experience, and does not include any multiplayer features yet.

At this point, the game is not yet playable, and only serves me as a personal project to learn and practice Java, Spring Boot, and Nuxt.
